# 🎯 GUIDE D'UTILISATION - POPUP DÉTAILLÉ DES LIEUX

## 📱 Comment utiliser les nouveaux popups

### **1. Ouvrir le popup détaillé**

1. Ouvrez l'application de géolocalisation Cotonou
2. Allez dans l'onglet **"Carte"**
3. **Cliquez sur n'importe quel marqueur** sur la carte
4. Le popup détaillé s'ouvre automatiquement

### **2. Navigation dans le popup**

#### **🖼️ Carrousel d'images**

- **Glissez horizontalement** pour voir les différentes photos
- Les **points en bas** indiquent l'image active
- Si aucune image : placeholder informatif affiché

#### **💝 Bouton favoris**

- **Cliquez sur le cœur** en haut à droite
- Animation élastique confirme l'action
- Couleur rouge = lieu en favoris
- Couleur grise = lieu non favori

#### **📊 Section évaluation**

- **Note moyenne** affichée avec couleur :
  - 🟢 Vert : 4+ étoiles (excellent)
  - 🟠 Orange : 3-4 étoiles (bon)
  - 🔴 Rouge : moins de 3 étoiles
- **Étoiles visuelles** pour note rapide
- **Nombre d'avis** entre parenthèses

#### **🕒 Horaires d'ouverture**

- **Jour actuel mis en évidence** en bleu
- Format lisible : "08:00-18:00" ou "24h/24"
- Section repliable pour économiser l'espace

#### **📞 Informations de contact**

- **Téléphone** : cliquable pour appeler directement
- **Site web** : cliquable pour ouvrir le navigateur
- Section invisible si aucune info disponible

### **3. Actions disponibles**

#### **🎯 Boutons principaux**

- **Itinéraire** 🧭 : Ouvre l'écran de navigation
- **Partager** 📤 : Partage le lieu via vos apps
- **Google Maps** 🗺️ : Ouvre dans l'application Maps
- **Appeler** ☎️ : Lance un appel (si numéro disponible)

### **4. Section commentaires**

#### **📝 Lire les avis**

- **Commentaires récents** affichés en premier
- **Avatar utilisateur** généré automatiquement
- **Date relative** : "Il y a 2 jours", "1 semaine"
- **Note par étoiles** pour chaque avis

#### **✍️ Ajouter un commentaire**

1. Cliquez sur **"Ajouter"** en haut à droite
2. Écrivez votre commentaire
3. Donnez une note de 1 à 5 étoiles
4. Cliquez **"Publier"**

### **5. Fonctionnalités avancées**

#### **📏 Distance**

- **Distance calculée** depuis votre position
- Affichage en mètres ou kilomètres
- Mise à jour automatique si vous bougez

#### **🎨 Interface adaptive**

- **Hauteur ajustable** : tirez la poignée en haut
- **Scroll vertical** pour contenu long
- **Background transparent** pour effet moderne

#### **🔄 Actualisation**

- **Données en temps réel** via internet
- **Cache local** pour navigation rapide
- **Synchronisation automatique**

## 💡 Conseils d'utilisation

### **🚀 Navigation rapide**

- **Glissez vers le bas** pour fermer le popup
- **Tirez vers le haut** pour voir plus de contenu
- **Appui long** sur image pour zoom (future version)

### **⭐ Maximiser l'expérience**

- **Activez la géolocalisation** pour distance précise
- **Connectez-vous à internet** pour images et commentaires
- **Ajoutez vos lieux favoris** pour accès rapide

### **🔧 Résolution de problèmes**

#### **Images ne s'affichent pas**

- Vérifiez votre connexion internet
- Placeholder automatique si problème réseau

#### **Distance incorrecte**

- Autorisez la géolocalisation dans les paramètres
- Redémarrez l'app si nécessaire

#### **Boutons non réactifs**

- Assurez-vous d'avoir la dernière version
- Fermez et rouvrez le popup
